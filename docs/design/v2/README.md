# Doem v2 design planning

- `v2_design/`: the Soft Studio mockups. `final/soft.html` is the target design; `explorations/` holds earlier directions and the stageshow source.
- `v2_build_plan.md`: the phase-by-phase plan for building v2 from the mockup.
- `decisions.md`: numbered design and build decisions made along the way.
- `redesign_current_ui_problems.md`: the 46 problems in the old UI, grouped under 8 root causes.
- `redesign_features.md`: features seen in 13 other task managers, for ideas.
- `doem_rebrand_plan.md`: the plan for renaming Tempo to Doem.

Paths inside these files (rebuild/, scripts/v2-gates.sh, tempo-* agents) point at material removed from the tree; it lives in the archive and git history.
