# Tempo v2 design

## Final mockup

**[final/soft.html](final/soft.html)**: Soft Studio, the chosen v2 direction. Open it in a browser.

It has five screens: Today, Next 7 days, Calendar, Tracking and the MSM26 project board. Switch between them with the sidebar, or add `#week`, `#calendar`, `#tracking` or `#project` to the address. The moon/sun button in the top bar switches light and dark. The task content is invented. Settings, Search and Trash are not mocked yet.
